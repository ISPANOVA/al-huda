# 🌙 الهدى — Al-Huda

تطبيق إسلامي متكامل لنظامي **أندرويد وiOS** مبني بإطار **Flutter**، بتصميم زجاجي فاخر (Glassmorphism) يجمع: المصحف الشريف مع التفسير الميسر، تلاوات متزامنة مع تظليل الآيات، وضع الحفظ والتكرار، التحميل للاستماع دون إنترنت، مواقيت الصلاة، بوصلة القبلة ثلاثية الأبعاد، الأذكار، المسبحة الإلكترونية، مخطط الختمة، وإحصائيات الالتزام اليومي.

| البند | القيمة |
|---|---|
| اسم التطبيق | الهدى (Al-Huda) |
| معرّف الحزمة (Android / iOS) | `com.alhuda.islamic.app` |
| إطار العمل | Flutter 3.38 أو أحدث (Dart 3.10+) |
| إدارة الحالة | flutter_bloc (Cubit) |
| البنية | Clean Architecture + Feature-First |

## ✨ المميزات

### 🎧 مشغل التلاوات المتقدم
- **أربعة قرّاء:** مشاري العفاسي، عبد الباسط عبد الصمد، محمود خليل الحصري، محمد صديق المنشاوي.
- **تظليل الآية المتزامن مع الصوت:** التلاوة مقسّمة إلى مقاطع على مستوى الآية، فيُظلَّل النص وينتقل المصحف تلقائيًا إلى الآية المتلوّة بدقة تامة.
- **وضع الحفظ:** اختيار بداية (سورة/آية) ونهاية (سورة/آية) حتى عبر عدة سور، مع عدد تكرار لكل آية وعدد تكرار للنطاق كاملًا أو تكرار لا نهائي.
- **التحميل دون إنترنت:** تنزيل أي سورة لأي قارئ عبر `dio` و`path_provider` مع استئناف التحميل المنقطع وإلغائه وحذفه.
- **التشغيل في الخلفية وأزرار شاشة القفل:** عبر `audio_service` (إشعار وسائط، سماعات، بلوتوث).
- التحكم في سرعة التلاوة (٠٫٥× إلى ٢×) وإضافة البسملة تلقائيًا قبل كل سورة.

### 📖 المصحف وأدوات التدبر
- النص العثماني كاملًا مع **التفسير الميسر** (عرض تحت الآيات أو في نافذة منفصلة).
- **بحث فوري** في الآيات دون حساسية للتشكيل، يعمل دون إنترنت بعد تنزيل المصحف (≈ ٦ ميجابايت).
- العلامات المرجعية، الآيات المفضلة، ومتابعة آخر موضع قراءة تلقائيًا.
- **خطوط قرآنية:** أميري قرآن (عثماني)، شهرزاد، النسخ — مع التحكم في حجم الخط وتباعد الأسطر.
- نسخ الآية ومشاركتها مع تفسيرها.

### 📅 مخطط الختمة
- تحديد مدة الختمة (أيام جاهزة أو مخصصة من ٣ إلى ٣٦٥ يومًا).
- حساب ورد يومي **تكيفي** يعيد توزيع المتبقي إن تأخرت أو سبقت، مع أشرطة تقدم يومية وكلية.
- تذكير يومي بالإشعارات في الوقت الذي تختاره، وعدّاد للختمات المكتملة.

### 🕌 مواقيت الصلاة والقبلة
- حساب فلكي دقيق **دون إنترنت** عبر مكتبة `adhan` وموقع GPS، مع ١٢ طريقة حساب (منها الهيئة المصرية وأم القرى ورابطة العالم الإسلامي) والمذهب الحنفي/الشافعي للعصر.
- بطاقة زجاجية بعدّ تنازلي حيّ وحلقة تقدّم حتى الصلاة القادمة، وتنبيهات عند دخول كل وقت.
- **بوصلة قبلة ثلاثية الأبعاد** بمستشعر البوصلة (`flutter_compass`) وميلان المقياس (`sensors_plus`)، مع اهتزاز وتوهج عند الاتجاه الصحيح والمسافة إلى الكعبة.

### 📿 الأذكار والمسبحة والإحصائيات
- أذكار الصباح والمساء وبعد الصلاة والنوم من «حصن المسلم» مع المصدر والفضل وعدّاد لكل ذكر يُعاد تلقائيًا كل يوم، وتلاوة صوتية للأذكار القرآنية (آية الكرسي، المعوذات، خواتيم البقرة).
- **مسبحة إلكترونية زجاجية** بحبات مضيئة، أهداف (٣٣، ٩٩، ١٠٠، ١٠٠٠، مفتوح)، أذكار مخصصة واهتزاز.
- **سلسلة الأيام المتتالية** وأطول سلسلة، مخطط آخر ٧ أيام، ومجاميع الآيات المقروءة والمسموعة والأذكار والتسبيح.

### 🎨 نظام التصميم الزجاجي
- أربعة ثيمات: **زمردي زجاجي** (افتراضي)، **أزرق أندلسي**، **ذهبي فاخر**، **أوبسيديان ليلي**.
- وضع فاتح/داكن/تلقائي حسب النظام، وتبديل فوري للثيم مع حركة انتقالية.
- زجاج متجمّد حقيقي (`BackdropFilter`) بحدود مزدوجة وتدرجات حيوية وزخرفة نجمية إسلامية خفيفة، مع «زجاج خفيف» داخل القوائم الطويلة للحفاظ على الأداء.
- واجهة عربية بالكامل من اليمين إلى اليسار وأرقام عربية مشرقية.

## 1️⃣ تثبيت البرامج المطلوبة

| البرنامج | الاستخدام | رابط التحميل الرسمي |
|---|---|---|
| **Flutter SDK** (3.38 أو أحدث) | إطار العمل ولغة Dart | https://docs.flutter.dev/get-started/install |
| **Android Studio** | Android SDK والمحاكي | https://developer.android.com/studio |
| **Java JDK 17** | بناء مشاريع أندرويد (Gradle) | https://adoptium.net/temurin/releases/?version=17 |
| **Git** | مطلوب لعمل Flutter | https://git-scm.com/downloads |
| VS Code (اختياري) | محرر خفيف مع إضافة Flutter | https://code.visualstudio.com/ |

### خطوات الإعداد
1. **Flutter:** نزّل الحزمة المناسبة لنظامك وفك ضغطها في مسار لا يحتوي مسافات أو حروفًا عربية (مثل `C:\src\flutter` أو `~/development/flutter`)، ثم أضف المجلد `flutter/bin` إلى متغير البيئة `PATH`.
2. **Android Studio:** ثبّته ثم افتح *More Actions ← SDK Manager* وتأكد من تثبيت:
   - Android SDK Platform (أحدث إصدار)
   - Android SDK Command-line Tools
   - Android SDK Build-Tools و Platform-Tools
   - ثبّت إضافتي **Flutter** و **Dart** من *Plugins*.
3. **JDK 17:** ثبّته واضبط `JAVA_HOME` عليه (يأتي Android Studio مع JDK مدمج يكفي غالبًا)، ويمكنك ربط Flutter به:
   ```bash
   flutter config --jdk-dir "<مسار JDK 17>"
   ```
4. اقبل تراخيص أندرويد وتحقق من البيئة:
   ```bash
   flutter doctor --android-licenses
   flutter doctor
   ```
   يجب أن تظهر علامة ✓ أمام Flutter و Android toolchain.

## 2️⃣ إعداد المشروع (أمر واحد)

من داخل مجلد المشروع `al_huda`:

**ويندوز:**
```bat
setup.bat
```

**macOS / Linux:**
```bash
chmod +x setup.sh
./setup.sh
```

يقوم السكربت تلقائيًا بما يلي:
1. `flutter create` لتوليد مجلدات المنصات الأصلية (android، و ios على macOS) دون المساس بالكود.
2. `flutter pub get` لتثبيت جميع الحزم.
3. `dart run tool/configure_platforms.dart` الذي يضبط:
   - معرّف الحزمة `com.alhuda.islamic.app` لأندرويد و iOS.
   - أذونات الموقع والإنترنت والإشعارات والتشغيل في الخلفية.
   - خدمة `audio_service` و `AudioServiceActivity` لأزرار شاشة القفل.
   - مستقبلات الإشعارات المجدولة و Desugaring المطلوب لها.
   - توقيع الإصدار من ملف `key.properties` إن وُجد.
   - `Info.plist` في iOS (رسائل الأذونات، وضع الصوت في الخلفية، الاسم «الهدى»).
4. توليد أيقونات التطبيق عبر `flutter_launcher_icons`.

> السكربت آمن لإعادة التشغيل أكثر من مرة.

## 3️⃣ التشغيل على محاكي أندرويد

1. افتح Android Studio ← *More Actions ← Virtual Device Manager* ← *Create Device*، اختر جهازًا (مثل Pixel 8) وصورة نظام حديثة تحتوي **Google Play/APIs**، ثم أنهِ الإنشاء.
2. من الطرفية:
   ```bash
   flutter emulators                    # عرض المحاكيات المتاحة
   flutter emulators --launch <اسم_المحاكي>
   flutter devices                      # التأكد من ظهور المحاكي
   flutter run
   ```
3. لتجربة المواقيت والقبلة على المحاكي: من قائمة المحاكي *⋮ ← Location* حدد موقعًا ثم اضغط *Set Location*. (مستشعر البوصلة الحقيقي متاح على الأجهزة الفعلية فقط.)

أثناء التشغيل: اضغط `r` لإعادة التحميل السريع، و `R` لإعادة التشغيل الكامل، و `q` للخروج.

## 4️⃣ التشغيل على هاتف أندرويد حقيقي (USB Debugging)

1. على الهاتف: *الإعدادات ← حول الهاتف* واضغط على **رقم الإصدار (Build number)** سبع مرات لتفعيل «خيارات المطوّر».
2. *الإعدادات ← النظام ← خيارات المطوّر* ← فعّل **تصحيح أخطاء USB (USB debugging)**.
3. صِل الهاتف بالحاسوب بكابل بيانات، ووافق على نافذة «السماح بتصحيح أخطاء USB» على الهاتف.
4. على ويندوز قد تحتاج تعريف الهاتف: [Google USB Driver](https://developer.android.com/studio/run/win-usb) أو تعريف الشركة المصنّعة.
5. من الطرفية:
   ```bash
   adb devices            # يجب أن يظهر الجهاز بحالة device
   flutter devices
   flutter run -d <معرّف_الجهاز>
   ```
6. لتجربة الأداء الحقيقي بلا أدوات التصحيح:
   ```bash
   flutter run --release
   ```

> **ملاحظة:** عند أول تشغيل اسمح بأذونات الموقع والإشعارات. وعلى بعض الأجهزة (شاومي، هواوي، سامسونج) يُستحسن استثناء التطبيق من «تحسين البطارية» لضمان وصول تنبيهات الصلاة في وقتها.

## 5️⃣ بناء نسخة الإصدار (APK / AAB)

### أ) إنشاء مفتاح التوقيع (مرة واحدة فقط)
```bash
keytool -genkey -v -keystore ~/alhuda-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias alhuda
```
(على ويندوز استبدل `~/alhuda-release.jks` بمسار مثل `C:\keys\alhuda-release.jks`.)

### ب) إنشاء الملف `android/key.properties`
```properties
storePassword=كلمة_مرور_المخزن
keyPassword=كلمة_مرور_المفتاح
keyAlias=alhuda
storeFile=/المسار/الكامل/alhuda-release.jks
```
> ⚠️ لا ترفع هذا الملف ولا ملف `.jks` إلى أي مستودع عام، واحتفظ بنسخة احتياطية منهما؛ فبدونهما لا يمكنك تحديث التطبيق على المتجر. (هما مُدرجان مسبقًا في `.gitignore`.)

إن كنت أنشأت `key.properties` بعد تشغيل `setup` فلا حاجة لأي خطوة إضافية؛ إعداد Gradle يقرؤه تلقائيًا عند البناء.

### ج) أوامر البناء
```bash
# APK عام لكل المعالجات
flutter build apk --release

# APK أصغر حجمًا لكل معمارية معالج
flutter build apk --release --split-per-abi

# حزمة AAB للنشر على Google Play (الموصى بها)
flutter build appbundle --release
```

**مسارات الملفات الناتجة:**
- `build/app/outputs/flutter-apk/app-release.apk`
- `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` (عند `--split-per-abi`)
- `build/app/outputs/bundle/release/app-release.aab`

لتثبيت الـ APK مباشرة على هاتف متصل:
```bash
flutter install
# أو
adb install build/app/outputs/flutter-apk/app-release.apk
```

لرفع رقم الإصدار قبل كل نشر عدّل السطر في `pubspec.yaml`:
```yaml
version: 1.0.1+2   # اسم الإصدار + رقم البناء
```

## 6️⃣ النشر على متجر Apple App Store (iOS) — دون أي تعديل في الكود

الكود مشترك بالكامل بين المنصتين، وكل ما يلزم هو بيئة Apple:

### المتطلبات
- جهاز **Mac** بأحدث نظام macOS.
- **Xcode** من Mac App Store: https://apps.apple.com/app/xcode/id497799835
- **CocoaPods**: `sudo gem install cocoapods` (أو `brew install cocoapods`) — https://cocoapods.org
- حساب **Apple Developer Program** (اشتراك سنوي): https://developer.apple.com/programs/

### الخطوات
1. انقل مجلد المشروع إلى جهاز الـ Mac وشغّل:
   ```bash
   ./setup.sh
   ```
   على macOS يولّد السكربت مجلد `ios` ويضبط معرّف الحزمة `com.alhuda.islamic.app` وأذونات الموقع والحركة ووضع الصوت في الخلفية داخل `Info.plist` تلقائيًا.
2. ثبّت اعتماديات iOS:
   ```bash
   cd ios && pod install && cd ..
   ```
3. افتح `ios/Runner.xcworkspace` في Xcode ← اختر هدف **Runner** ← تبويب **Signing & Capabilities**:
   - اختر فريقك (Team) وفعّل *Automatically manage signing*.
   - تأكد أن **Background Modes ← Audio** مفعّل (يضيفه السكربت، ويمكنك التحقق منه هنا).
4. جرّب على جهاز iPhone حقيقي:
   ```bash
   flutter run --release
   ```
5. أنشئ سجل التطبيق في **App Store Connect** (https://appstoreconnect.apple.com) بنفس معرّف الحزمة `com.alhuda.islamic.app`.
6. ابنِ حزمة الرفع:
   ```bash
   flutter build ipa --release
   ```
   الناتج في `build/ios/ipa/`، وارفعه عبر تطبيق **Transporter** (https://apps.apple.com/app/transporter/id1450874784) أو من Xcode: *Product ← Archive ← Distribute App*.
7. من App Store Connect: جرّب عبر **TestFlight**، ثم أكمل بيانات المتجر (الوصف، لقطات الشاشة، سياسة الخصوصية، تصنيف المحتوى) وأرسل للمراجعة.

> **سياسة الخصوصية:** يستخدم التطبيق الموقع لحساب المواقيت والقبلة محليًا فقط، ولا يجمع أي بيانات شخصية أو يرسلها لأي خادم. اذكر ذلك في نموذج «App Privacy».

## 🛠️ حل المشكلات الشائعة

| المشكلة | الحل |
|---|---|
| `flutter` غير معروف في الطرفية | تأكد من إضافة `flutter/bin` إلى `PATH` ثم أعد فتح الطرفية. |
