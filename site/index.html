الحفظ

إزاي أعمل المفتاح؟ (مرة واحدة بس)
  1. افتح github.com/settings/personal-access-tokens/new
  2. اكتب أي اسم، واختار مدة (مثلًا سنة).
  3. في Repository access اختار Only select repositories ثم al-huda.
  4. في Permissions ← Contents اختار Read and write.
  5. اضغط Generate وانسخ المفتاح وحطه هنا. المفتاح ده بتاعك انت بس، ومن غيره محدش يقدر يغيّر الرسالة.
